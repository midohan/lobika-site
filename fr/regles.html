Les règles du padel en 2026, telles que Lobika les compte

Le décompte des points, du jeu, du set et du match en double, avec, pour chaque règle, son origine : le règlement, une déduction, ou un choix de l'application.

Chaque règle porte une étiquette. Règlement : écrite dans le règlement international du jeu, édition en application au 1ᵉʳ janvier 2026 (voir les sources en bas de page). Déduit : pas écrite telle quelle, mais conséquence de textes du règlement. Choix de l'app : ni écrite ni déductible, c'est un choix de Lobika, dit comme tel. Rien ici n'est un document officiel, et les clubs peuvent jouer autrement.

Le jeu

RèglementLes points d'un jeu se disent 15, 30, 40, puis jeu. À 40-40, c'est l'égalité. Ce qui se passe ensuite dépend du mode de jeu choisi avant le match ; le règlement en propose trois, et chaque circuit ou chaque club choisit le sien.

AvantageLe point suivant donne l'avantage ; la même paire gagne le suivant, elle gagne le jeu ; sinon retour à l'égalité, sans limite.sans limite
Point en orUn seul point décide du jeu, dès la première égalité.7 points
Deux avantages, puis point décisifPremière égalité, avantage ; perdu, deuxième égalité, avantage ; perdu, troisième égalité, puis un point décisif.11 points

DéduitLes durées « 7 points » et « 11 points » se déduisent du déroulé : au point en or, le septième point décide ; avec deux avantages, les égalités tombent au sixième, au huitième et au dixième point, le onzième décide.

Le point décisif : qui choisit quoi

RèglementAu point décisif, la paire qui reçoit choisit de recevoir à droite ou à gauche ; ses deux joueurs ne changent pas de position pour ce point. En mixte, le receveur est du même sexe que le serveur, et les receveurs ne changent pas de position.

DéduitComme les joueurs gardent leur place, choisir le côté revient à choisir lequel des deux reçoit ; le serveur sert alors depuis la moitié qui correspond à ce côté. En mixte, le côté est donc imposé : un seul des deux receveurs est du bon sexe.

À confirmer par un arbitre : le règlement ne dit pas de quel point de vue se lisent « droite » et « gauche ». Lobika les prend face au filet, du point de vue du joueur concerné : le serveur à sa droite sert dans la boîte qui est, pour le receveur en face, à sa droite aussi.

Le côté de service à chaque point

RèglementLe serveur alterne les côtés d'un point au suivant.

DéduitLe premier point d'un jeu se sert de la droite, le deuxième de la gauche, et ainsi de suite : droite aux points impairs, gauche aux points pairs, sauf au point décisif, où la paire qui reçoit choisit.

Le set

RèglementUn set se gagne à 6 jeux avec 2 jeux d'écart. À 5-5, on joue deux jeux de plus, jusqu'à 7-5. À 6-6, un tie-break.

Le tie-break

RèglementLes points se comptent zéro, 1, 2, 3… Le tie-break se gagne à 7 points avec 2 d'écart, prolongé s'il le faut ; il vaut le jeu et le set, qui se termine 7-6. Il est commencé par le joueur dont c'est le tour de servir ; ce joueur ne sert qu'un point. Les deux points suivants sont servis par la paire adverse, puis chaque joueur sert deux points de suite, dans l'ordre du set. On change de côté tous les 6 points. L'ordre de réception ne change pas pendant le tie-break.

RèglementLe set suivant est commencé par la paire qui n'a pas servi le premier point du tie-break.

DéduitAvec un ordre de service A, C, B, D et A au premier point, les serveurs des points 1 à 14 sont : A, C, C, B, B, D, D, A, A, C, C, B, B, D. Le côté : droite aux points impairs, gauche aux points pairs. Le tie-break compte pour un jeu, le treizième du set, donc impair : un changement de côté est dû après lui ; s'il se termine sur un multiple de 6 points, ce changement et celui « tous les 6 points » n'en font qu'un.

Trois lectures à confirmer par un arbitre : le même joueur de la paire adverse sert les points 2 et 3 ; le point 3 se sert de la droite ; « le joueur de la paire qui n'a pas commencé à servir » se lit comme la paire adverse.

Le premier serveur d'un set

RèglementAvant chaque set, chaque paire choisit qui sert en premier pour elle ; l'ordre ne change qu'au set suivant.

Choix de l'appSans tie-break avant, Lobika propose que le set commence par la paire qui n'a pas servi le dernier jeu du set précédent, et, dans chaque paire, par l'autre joueur que celui qui a servi en premier au set précédent. C'est une proposition : tu peux déclarer autre chose, et l'application compte ce que tu déclares.

Le match

RèglementLe match se joue au meilleur des trois sets : deux sets gagnants.

RèglementÀ un set partout, un super tie-break peut remplacer le troisième set, si c'est convenu avant : la première paire à 10 points avec 2 d'écart gagne le match. Il ne se termine jamais avant 10 points.

Choix de l'appLe règlement ne dit pas qui sert en premier dans le super tie-break, ni quand on change de côté. Lobika lui applique les règles du tie-break : même ordre de service des points, mêmes côtés, changement tous les 6 points ; à la fin, le match est terminé, aucun changement n'est dû.

Choix de l'appLe match en un set n'est pas un format du règlement : c'est un format de Lobika pour les matchs de club et les échauffements ; le set lui-même suit la règle ci-dessus.

Choix de l'appLa fin de créneau n'existe pas dans le règlement, qui ne prévoit ni durée maximale ni score à l'arrêt. Dans Lobika, à l'heure de fin que tu as saisie, la montre propose d'arrêter ; d'un tap, le score est figé et le match est noté « non terminé », sans vainqueur ; il compte dans l'historique et les points, pas dans les victoires et les défaites. Annuler l'arrêt reprend le match là où il en était.

Le service en double

RèglementL'ordre de service est choisi avant chaque set et ne change qu'au set suivant. Au premier jeu de chaque set, la paire qui reçoit décide qui reçoit le premier service ; ce joueur reçoit le premier service de chaque jeu jusqu'à la fin du set, puis chacun reçoit à tour de rôle.

DéduitLes quatre joueurs servent à tour de rôle, une paire puis l'autre : A, C, B, D. Un joueur sert tout son jeu, en alternant les côtés. Le premier service d'un jeu venant de la droite, le premier receveur est le joueur de droite de sa paire pour tout le set ; l'autre est le joueur de gauche.

Le changement de côté

RèglementLes paires changent de côté après le premier jeu, le troisième, et tout jeu impair du set ; dans un tie-break, tous les 6 points.

DéduitUn set qui se termine sur un nombre impair de jeux (6-1, 6-3, 7-6) donne un changement de côté avant le premier jeu du set suivant ; un set qui se termine sur un nombre pair (6-4, 7-5) n'en donne pas avant la fin du premier jeu du set suivant.

Ce que Lobika ne compte pas

Les fautes de service, les lets, les interférences, les pénalités, les erreurs de service ou de réception, les suspensions, le tie-break à 7 points décisif, le mini-set à 4 jeux et le troisième set sans tie-break existent dans le règlement : Lobika saisit des points, pas des fautes, et ne tient pas lieu d'arbitre.
